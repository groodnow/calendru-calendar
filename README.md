# Автоматический календарь государственных праздников России

Репозиторий ежедневно загружает календарь Calend.ru, удаляет повторы и публикует очищенный ICS-файл через GitHub Pages.

## Как работает обновление

- Ежедневно в **07:15 по времени Алтайского края (UTC+7)** запускается GitHub Actions.
- Источник — официальный ICS-адрес Calend.ru с параметром текущего года.
- Удаляются значения `RDATE`, совпадающие с `DTSTART` того же события.
- Если один `UID` встречается несколько раз, сохраняется наиболее поздняя версия по `LAST-MODIFIED` или `DTSTAMP`.
- При ошибке загрузки или пустом календаре прежний файл не перезаписывается.
- Если содержимое не изменилось, новый commit не создаётся.

## Включение публикации GitHub Pages

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/docs**.
4. Нажмите **Save**.

После успешной публикации адрес календаря:

`https://groodnow.github.io/calendru-calendar/calend-russtate.ics`

## Первый запуск

1. Откройте вкладку **Actions**.
2. Выберите workflow **Update Calend.ru calendar**.
3. Нажмите **Run workflow** и подтвердите запуск.
4. Дождитесь успешного завершения. Workflow создаст или обновит `docs/calend-russtate.ics`.

## Подписка в Google Calendar

1. Откройте Google Calendar в браузере.
2. Рядом с **Другие календари** нажмите **+**.
3. Выберите **По URL**.
4. Вставьте адрес:

   `https://groodnow.github.io/calendru-calendar/calend-russtate.ics`

5. Нажмите **Добавить календарь**.

Важно: выбирайте именно **«По URL»**, а не «Импорт». Google самостоятельно обновляет подписанные календари; задержка обновления на стороне Google возможна и не регулируется этим репозиторием.

## Исходный источник

`https://www.calend.ru/ical/ical-russtate.ics?v=yyГОД&b=1`

Год в параметре URL автоматически определяется по часовому поясу Алтайского края.
